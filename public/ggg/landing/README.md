Use the updated Specialty Cartridge packaging throughout. All product imagery is conceptual artwork, not verified SKU photography. Coral/plum/lavender are packaging concepts, not confirmed product options. Preserve the Specialty Cartridge branding.

- icon-search.svg / icon-bag.svg / icon-arrow-right.svg: UI icons; Instagram original artwork supplied separately.

- reference-landing-original.png: layout reference only. Its old GGG-branded boxes are superseded by the supplied Specialty Cartridge assets.
- reference-hero-updated.png: updated hero visual reference only, not a production background because it contains text/buttons.

## Render as HTML/CSS
Navigation, headings, body copy, product names, buttons, brand-repeat strip, flower separators, forms and footer links. Do not bake these into images. Use CSS border radii, shadows and responsive grids. Brand palette: #F7F1FC #E73C28 #E032A3 #226663 #6E5084.

Brand guide specifies Picky Retro headings and Goodly secondary text. Font binaries are not included in the supplied package; obtain licensed webfont files separately. Generated mockups approximate those fonts.

Replace placeholder product data with real catalog details. Do not infer separate calibers from packaging colorways.
